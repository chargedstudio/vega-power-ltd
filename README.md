# Vega Power — demo site

A single-page marketing site for Vega Power Ltd (on-site commercial solar PPAs).
Next.js (App Router) + TypeScript + Tailwind + Framer Motion. Fully static — no
backend, no database, no auth. Deploys to Vercel with zero configuration.

## Run it locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

To check the production build:

```bash
npm run build
npm start
```

## Push to GitHub

```bash
git init
git add .
git commit -m "Vega Power demo site"
git branch -M main
git remote add origin https://github.com/<you>/vega-power.git
git push -u origin main
```

(`node_modules` and `.next` are git-ignored — you can safely delete those two
folders locally; they are regenerated by `npm install` / `npm run build`.)

## Deploy to Vercel

1. Go to vercel.com → **Add New… → Project**.
2. Import the GitHub repo.
3. Framework preset auto-detects **Next.js** — leave every setting default.
4. **Deploy.** You get a live `*.vercel.app` URL in ~1 minute.

No environment variables, no build overrides, no custom server.

## Structure

```
app/
  layout.tsx        Root layout, metadata, Inter font (loaded via <link>)
  page.tsx          Assembles all sections in order
  globals.css       Brand tokens, slat motif, blueprint texture, slider styling
components/
  Nav.tsx           Sticky nav, mobile menu
  Hero.tsx          Problem-led hero + animated grid-vs-fixed price visual
  HowItWorks.tsx    Survey & Design → Install → Supply → Manage
  PpaFlowDiagram.tsx Animated PPA flow (horizontal on desktop, stacked on mobile)
  WhyVega.tsx       The PPA model: "what you keep / what we carry"
  SavingsEstimator.tsx  Interactive sliders → live savings (real model in lib/)
  Proof.tsx         Assurances + sector wall + sample testimonial (swap-ready)
  ServiceAreas.tsx  GB coverage
  FinalCTA.tsx      Survey CTA + demo contact form (no backend)
  Footer.tsx
  ui/               VegaLogo (vector), Reveal (scroll animation), CountUp, SectionLabel
lib/
  estimate.ts       The savings model + all assumptions, in one place
```

## What to customise before sending / going live

- **Contact details** — phone, email and form behaviour in `components/FinalCTA.tsx`
  (the form is front-end only; wire it to email/CRM before real use).
- **Savings assumptions** — grid rate, Vega rate, yield, etc. live at the top of
  `lib/estimate.ts`. Every figure on the estimator is labelled "illustrative".
- **Sample testimonial & sector wall** — `components/Proof.tsx`. The testimonial
  is tagged "Sample"; replace with real client quotes/logos once signed.
- **Logo** — rebuilt as crisp vector in `components/ui/VegaLogo.tsx`. Swap in the
  official asset if you have an SVG.

## Notes

- `robots` is set to `noindex` in `app/layout.tsx` so the demo doesn't get
  indexed. Remove that line for the live site.
- Respects `prefers-reduced-motion` throughout.
